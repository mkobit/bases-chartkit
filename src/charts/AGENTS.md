# Chart transformers

This directory contains ECharts option builders and chart transformers.

## Color and data visualization guidelines
- When you change chart color palettes, gradients, legends, or axes, consult [.agents/references/dataviz.md](../../.agents/references/dataviz.md).
- Follow the rules to select categorical, sequential, or diverging palettes.
- Verify color contrast and color-vision deficiency safety.
